# 진입오류 분석 에이전트

개인화 매매 복기 서비스 "왜 잃었지?"의 하위 모듈입니다.

이 프로젝트는 실시간 매매 추천 시스템이 아니라, 이미 종료된 거래를 사후에 복기하기 위한 MVP입니다. 진입 시점의 가격 위치, 추세, 거래량, 변동성 맥락을 바탕으로 사용자가 어떤 상태에서 진입했는지 설명하는 방향으로 설계합니다.

현재 단계에서는 실제 CSV 데이터가 아직 준비되지 않았으므로 `sample_data/tiny_mock.csv`를 기준으로 프로젝트 구조와 코드 뼈대만 확인합니다. 로컬 환경에서는 무거운 실행을 하지 않고, 이후 Google Colab에서 실제 데이터 처리와 검증을 수행할 수 있도록 path 기반 함수 형태로 확장할 예정입니다.

## 현재 범위

- 프로젝트 폴더 구조 확인
- 입력 스키마와 모듈 역할 정리
- 실제 분석 로직이 없는 TODO 중심 코드 작성
- 작은 mock CSV 존재 여부 확인

현재 단계의 코드는 분석 결과를 만들지 않습니다.

## 실행 확인

```bash
python main.py
```

정상 구조라면 다음 메시지가 출력됩니다.

```text
Project structure is ready.
```

## 주의

- `.venv`를 만들지 않습니다.
- `pip install`을 실행하지 않습니다.
- 실제 증권사 API에 연결하지 않습니다.
- 머신러닝 모델을 사용하지 않습니다.
- 대용량 CSV를 생성하지 않습니다.
- pandas import는 아직 사용하지 않습니다.
